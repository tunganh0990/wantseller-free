# WantSeller Free

A free, local-first Windows desktop toolkit for marketplace sellers. This is an independent community rebuild using reference materials the project owner authorized for public release. It is not an official WantSeller vendor build.

## Download

Open Releases at https://github.com/tunganh0990/wantseller-free/releases for the Windows x64 installer and full source archive. The source ZIP contains the project tree, implementation plan, license notices, and build instructions.

## Included in 0.1.0 Alpha

- Local multi-shop records and CSV order import/export.
- Per-shop revenue and estimated profit summary with a seven-day chart.
- Local PDF catalog, text indexing, order-code search, and preview.
- Reply templates for manual copy/paste and draft seller-workflow checklists.
- No HWID gate, licensing server, platform session cookies, or telemetry endpoint.

## Current scope

The app does not connect to Shopee, TikTok Shop, or Lazada yet. Live order sync, inbox/chat send, marketplace actions, background automation, and OCR are not included. Review the source archive README and detailed plan before relying on this alpha operationally.
